# Excel-Inventory-Sales-Dashboard
Inventory and Sales Analysis Dashboard using Microsoft Excel 

I'm excited to share my Inventory & Sales Dashboard project, developed as part of my Data Analytics learning journey. 🚀

While working on this project, I learned how to analyze sales and inventory data using Microsoft Excel. I used PivotTables and PivotCharts to summarize and visualize the data, created KPI cards to track important business metrics, and used interactive slicers to filter the data.
I also analyzed monthly sales trends, product categories, supplier performance, warehouse sales, and stock status. Finally, I brought everything together into an interactive dashboard to present business insights clearly and effectively.
This project gave me practical experience in data analysis and helped me improve my Excel skills. 🚀

📌 Key Features:
✅ Monthly Sales Trend Analysis
✅ Category-wise Sales Analysis
✅ Supplier-wise Sales Performance
✅ Top 10 Products by Sales
✅ Warehouse-wise Sales Analysis
✅ Order Status Distribution
✅ Stock Status Analysis
✅ KPI Cards & Interactive Slicers

🛠️ Tools Used: Microsoft Excel, PivotTables, PivotCharts, Slicers, and Data Visualization.

🎯 Project Goal: *To analyze sales and inventory data and generate meaningful insights to support business decision-making.
